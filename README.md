# ccfolia-paste
ココフォリアにPDFから貼り付けた際に起こる変な改行を自動整形します。


## 導入方法
### GoogleChrome(Throrium、Edgeも同様)の場合
1. 必要ファイルをDLします。
2. `chrome://extensions`にアクセスします。(Edgeは`edge://extensions`)
3. 右上の「デベロッパーモード」をオンにします。
4. zipファイルをD&Dするか、展開したフォルダを「パッケージ化されていない拡張機能を読み込む」から選択してください。

### FireFox(DeveloperEdition、Nightly)の場合
1. CRX Installer(https://addons.mozilla.org/ja/firefox/addon/crxinstaller/ ​)をインストールします。
2. CRX Installerのページから「Choose file」(Install Manually from File)を選択し、DLした.zipファイルを選択します。



## 使い方

### 基本

1. ココフォリアのチャット欄など、**テキスト入力欄にカーソルを置きます**。
2. PDFからコピーした文章を、いつも通り **Ctrl+V** で貼り付けます。
3. PDFの折り返しによる不要な改行と、日本語中の不要な半角スペースが取り除かれた状態で入力されます。

整形したくないときは **Ctrl+Shift+V** で貼り付けてください。拡張機能は何もせず、ココフォリア標準の貼り付けになります。

### 整形の例

PDFからコピーした文章（ページ幅で改行され、見出しの後に空行がない）：

```
hogehogeの都、hoge神社
hoge神社は縁切り神社として有名だ。ここでは君
たちも縁切りや縁結びの願いが出来ることだろう。
```

貼り付け後：

```
hogehogeの都、hoge神社

hoge神社は縁切り神社として有名だ。ここでは君たちも縁切りや縁結びの願いが出来ることだろう。
```

PDFのスペースも取り除かれます（英文の単語間のスペースは残ります）。

```
ココフォリア 上で PDF から 直接貼り 付けした 際に 、 変な 改行が入る。iPhone XR
　↓
ココフォリア上でPDFから直接貼り付けした際に、変な改行が入る。iPhone XR
```

### 設定

ツールバーの拡張機能アイコンをクリックすると、設定画面が開きます。変更は保存され、次の貼り付けからすぐに反映されます（ページの再読み込みは不要です）。

| 項目 | 説明 |
| --- | --- |
| 改行を残す行の長さ（スライダー） | 全文で最も長い行に対して、この割合より短い行の後ろでは改行を残します。見出しが本文と繋がってしまう場合は右（1.0寄り）へ、文の途中で改行が残る場合は左（0.5寄り）へ動かします。初期値は 0.80 です。 |
| スペース削除（チェックボックス） | 日本語中の不要な半角スペースを削除します。初期値はオンです。 |
| メモ帳 | 整形されずにそのまま貼り付けられるテキスト欄です。貼り付けて手直しし、「コピー」で取り出せます。ココフォリアへは Ctrl+Shift+V で貼り付けてください（Ctrl+V だと再度整形されます）。内容は自動保存されます。 |

### うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 見出しが本文と繋がる | スライダーを右へ動かす |
| 文の途中で改行が残る | スライダーを左へ動かす |
| 整形結果が思い通りにならない | Ctrl+Shift+V で無加工貼り付け、またはメモ帳で手直しする |
| 日本語と英数字の間のスペースまで消える | スペース削除をオフにする |
| Ctrl+V で何も貼り付かない | 拡張機能の全ファイル（`manifest.json` を含む）が最新か確認し、`chrome://extensions` で更新ボタンを押してページを再読み込みする |

## 技術者向けの説明

### 構成

```
manifest.json   Manifest V3。content script と popup の定義
format.js       整形ロジック（純粋関数 formatText）
content.js      pasteイベントの捕捉、設定の読み込み、入力欄への挿入
popup.html      設定画面
popup.js        設定の保存・読み込み、メモ帳
```

- 権限は `storage` のみです。content script は `https://ccfolia.com/*` でだけ動作します。
- `format.js` は DOM に依存しないため、単体でテストできます。

### 動作の流れ

1. `document` の **capture フェーズ**で `paste` イベントを捕捉します。ページ側のハンドラより先に処理するためです。
2. 次のいずれかに該当する場合は何もせず、標準の貼り付けに任せます。
   - 貼り付け先が `HTMLTextAreaElement` でない、読み取り専用・無効、または `document.activeElement` と一致しない
   - `Ctrl+Shift+V`（`keydown` でフラグを立てておき、`paste` で判定）
   - クリップボードが空、または JSON として解釈できる `{...}`（いあきゃら等のキャラクターデータの取り込みを妨げないため）
3. `formatText(text, ratio, removeSpaces)` で整形します。**例外が出た場合は横取りせず**、標準の貼り付けに戻します。
4. 成功した場合のみ `preventDefault()` と `stopImmediatePropagation()` を呼び、整形後のテキストを挿入します。

### 挿入方法

ココフォリアの入力欄は React 管理の `<textarea>` です。`value` を直接書き換えても React の状態に反映されないため、まず `document.execCommand("insertText")` を使います。これにより、入力イベントが正しく発火し、Ctrl+Z で元に戻せます。失敗した場合は、`HTMLTextAreaElement.prototype` のネイティブ `value` セッターで値を設定し、`input` イベントを手動で発火します。

### 整形アルゴリズム

PDFから取り出した文章には、段落の区切りではなく**ページ幅での折り返し位置**に改行が入っています。見出しと本文の間の空行は、テキストには含まれないことが多いです。そこで次の手順で改行を判定します。

1. 改行コードを `\n` に統一します（`\r`、`U+2028`、`U+2029`、`VT`、`FF`、`NEL` を含む）。
2. `removeSpaces` が有効なら、日本語文字に隣接する半角スペース（U+0020）を削除します。両側が英数字などの場合は削除しないため、英文は影響を受けません。全角スペース（U+3000）は残します。
3. 全行の表示幅（全角 = 1、半角 = 0.5）の最大値を、PDFの折り返し幅とみなします。
4. 空行で段落に分割し、各段落内の行を順に連結します。次のいずれかに該当する行の後ろでは改行を残し、それ以外の改行は削除します。
   - 文末（`。！？!?》`、または `。！？!?` の後に閉じ括弧）で終わる
   - 括弧で始まり括弧で閉じる見出し行（`＜…＞`、`《…》`、`【…】` など）、またはその直後の行
   - 表示幅が `最大幅 × ratio` より短い
5. 英数字どうしが改行で繋がる場合は、半角スペースを挿入します。

### 設定の保存

| キー | 保存先 | 内容 |
| --- | --- | --- |
| `shortLineRatio` | `chrome.storage.sync` | スライダーの値（0.5〜1.0） |
| `removeSpaces` | `chrome.storage.sync` | スペース削除のオン/オフ |
| `memo` | `chrome.storage.local` | メモ帳の内容 |

content script は `chrome.storage.onChanged` を監視しており、popup での変更は再読み込みなしで反映されます。

### カスタマイズ

`format.js` の先頭にある定数を変更すると、挙動を調整できます。

- `PARAGRAPH_GAP`: 残す改行を空行付き（`"\n\n"`）にするか、詰める（`"\n"`）か
- `SENTENCE_END`: 文末とみなす文字
- `HEADING`: 見出し行とみなすパターン
- `JA`: 日本語文字として扱う Unicode 範囲

### 既知の制限

- 判定はヒューリスティックです。台詞や箇条書きなど、句点で終わらない短い行が続く文章では、意図と違う結果になることがあります。
- 短い文章や1〜2行だけの貼り付けでは、最長行を折り返し幅として推定するため、判定精度が下がります。
- 日本語と英数字の間のスペースも削除されます（例: `PDF から` → `PDFから`）。
- Chrome 系ブラウザ（Manifest V3）向けです。Firefox は未検証です。

### 単体テスト

`format.js` はトップレベルで定数を宣言しているため、Node.js では次のように読み込めます。

```js
const fs = require("fs");
const code = fs.readFileSync("format.js", "utf8") + "\nreturn formatText;";
const formatText = new Function(code)();

console.log(formatText("ココフォリア 上で PDF から 直接貼り 付けした", 0.8, true));
// => ココフォリア上でPDFから直接貼り付けした
```
